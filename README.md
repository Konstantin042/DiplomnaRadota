# Court Vision

Уебсайт за дипломна работа, който обяснява баскетбола и NBA на хора, които не ги познават.
Сайтът е написан на **C#** с **ASP.NET Core MVC (.NET 8)**. Текстът на страниците е на английски,
а коментарите в кода са на български – на всеки ред е обяснено какво прави.

## Какво има в сайта

| Страница | Какво прави |
|---|---|
| **Home** | Начална страница с връзки към всички части |
| **NBA 101** | Игрището, петте позиции и основните термини |
| **82-0** | Завърташ отбор и десетилетие, избираш 5 титуляри и 3 резерви от истинския състав и симулираш 82 мача |
| **Build-a-Player** | Сглобяваш играч от 10 атрибута на истински играчи, после играеш сезон, Play-In и плейофи |
| **Position Quiz** | Познаваш позицията на играч само по уменията му |

## Как се стартира

1. Инсталирай [Visual Studio 2022](https://visualstudio.microsoft.com/) с работното натоварване **ASP.NET and web development** (в него е .NET 8 SDK).
2. Отвори `CourtVision.sln`.
3. Натисни **F5** (или зеления бутон ▶ CourtVision). Сайтът се отваря на `http://localhost:5080`.

От командния ред (нужен е само .NET 8 SDK):

```
cd CourtVision
dotnet run
```

## Структура на проекта

```
CourtVision/
├── Program.cs              Стартиране: услуги, сесии, маршрути
├── Controllers/            Обработват заявките (по един за всяка игра)
├── Services/               Логиката на игрите: завъртания, оценки, симулации
├── Models/                 Класовете с данни (играчи, отбори, състояния на игрите)
├── Views/                  Razor изгледи (.cshtml) – HTML страниците
├── Data/                   JSON файлове със съставите, статистиките и оценките
└── wwwroot/                Статични файлове: CSS, JavaScript, снимки
```

## Как работи

* Цялата логика е на сървъра, в C#. Състоянието на всяка игра се пази в **сесията** на потребителя като JSON.
* Бутоните изпращат обикновени HTML формуляри към контролерите. JavaScript (`wwwroot/js`) само прави
  анимациите и подменя част от страницата без презареждане – резултатите винаги идват от сървъра.
* Статистиките на играчите са от [Basketball-Reference](https://www.basketball-reference.com/),
  а снимките – от официалните профили на играчите в NBA.com.
